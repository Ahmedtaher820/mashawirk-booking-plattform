# بنك كلمات البحث — مشاويرك (داخل الإمارات وخارجها)

الكلمات مدمجة في `title` / `description` / `H1` / body / روابط داخلية — **وليس** في `<meta name="keywords">`.

## أين تظهر كل مجموعة؟

| Cluster | الصفحات الأساسية |
|---|---|
| توصيل طرود / طلبات / نفس اليوم / مندوب توصيل / شحن داخلي | `/services/delivery` + صفحات المدن |
| كارليفت / مشوار خاص / توصيل موظفين / سائق خاص | `/services/car-lift` + مدن (خصوصًا دبي/الشارقة) |
| مندوب مبيعات / تسويق ميداني / خدمات أعمال | `/services/sales-rep` + هوم/خدمات |
| كورير / لوجستيات / last mile / شحن داخلي | `/services/courier` |
| توصيل خارج الإمارات SA/OM/QA | `/services/international` |
| مستلزمات / أغراض / بيك أب | `/services/supplies` + `/services/light-goods` |
| هدايا / VIP / حيوانات أليفة | `/services/gifts` `/vip` `/pets` |
